# OTG Pixel Game

OTG Pixel Game is a future 2D pixel-art game with a retro style. At this stage, only the bootstrap project has been created; gameplay logic has not been implemented.

## Structure

- `Game/` — the Godot project itself.
- `Game/project.godot` — the project file.
- `Game/scenes/` — scenes.
- `Game/scripts/` — GDScript scripts.
- `Game/assets/` — directories for future game assets.
- `DEV/docs/` — project context.
- `DEV/reports/` — task reports.
- `Tools/` — local tools that are not stored in Git.

## Local launch

1. Install Godot 4.7.2 Standard on the local computer.
2. Open `Game/project.godot` in Godot.
3. Use F6 to run the current scene or F5 to run the project.

Current status: the bootstrap has been created; engine validation and visual validation are pending on a computer with Godot installed.

Do not add executables, secrets, or generated Godot cache directories (`.godot` and `.import`) to Git.
